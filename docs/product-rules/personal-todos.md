# 个人待办

> **状态**：fork（kiwabb/cindy）专有产品规则。上游 2026-11-08 移除了 V1 伙伴待办，fork 于
> 2026-11-11 合并上游时跟随移除，只保留个人待办。

个人待办是主人自己记的清单，只属于当前登录账号、只存在运行 Cindy 的这台电脑上，与伙伴无关。

## 桌面「待办」页

- 左侧导航一级入口「待办」打开 `/bots/todos`（`TeammateTodosView.tsx`），只显示个人待办；
  侧栏入口的数是未完成的个人待办数。
- 列表顶部原地新增（2026-11-11 主人确认原型）：标题里的「明天下午3点」这类日期就地识别，可撤销。
- 每条可设优先级（高／中／低，用勾选圈颜色表示）、一个标签（与任务共用同一份标签目录）、截止与
  提醒方式；可按截止时间、优先级、标签分组或不分组，组内按优先级、截止或添加时间排序。
- 子任务（2026-11-11 主人确认原型，2026-11-12 步骤 v2 改版；界面称「步骤」，因为「子任务」已指后台子 Agent 任务、「任务」指 Session）：每条可带一份有序清单，每步有标题与完成状态，勾选后记下勾选时间；没有自己的
  截止、优先级或提醒，最多 50 步。有步骤的行最左是展开箭头，行内标题下显示「完成数/总数」；没有步骤的行悬停时最左出现「＋」，点开即可添加。
  展开后可直接勾选、删除，并用「添加步骤」添加：点「添加」或回车添加并继续输入下一步，离开输入框时有内容就添加、没内容就收起，Esc 取消。
  详情面板里步骤和同样的添加入口紧跟标题，在备注之前。都即时保存（整份清单随条目 revision 替换），不关闭面板、不丢正在编辑的其他字段。
  已勾选且有勾选时间的步骤在行尾显示时间（今天显示时分，其他日子显示月日，跨年带年份），桌面端行内与面板都显示；
  勾选前、取消勾选后或此功能前已勾选的步骤不显示。同步冲突草稿行的步骤只读。全部勾完不自动完成
  待办，完成待办也不改各步状态。本期不支持改步骤标题和拖动排序；手机只显示进度，不编辑，也不显示勾选时间。
- 详情面板可用标题右侧 ×、Esc 或再次点开同一行关闭；宽窗口下面板随列表固定，正文单独滚动，
  保存／完成／删除常驻底栏。
- 状态分进行中／稍后再说／已完成；完成、重开、稍后、删除都在页内直接做。

## 多台电脑同步（2026-11-11，默认关闭）

设计与协议见[共享数据集](../shared-datasets-plan.md)、[协议记录](../dev-rules/protocol-compatibility/shared-datasets.md)。

- 待办页的开关「在多台电脑间同步」打开后：同账号里已有主力电脑时，这台成为副本，先把本机已有待办带过去（已删除的不带，已完成的保持完成，稍后的保持稍后；已过期的稍后按未完成带过去），再显示主力电脑的清单；没有主力电脑时，这台成为主力电脑。关闭后本机留着当前这份清单，不再同步。
- **主力电脑是唯一写入者。** 副本上的修改先应用到本机并显示，同时进入待发队列；主力电脑在线时按顺序提交，离线时显示「待同步」，上线后补交。手机连哪台电脑就读写哪台电脑的这份清单，手机的写入同样走这条路径。
- **冲突不覆盖。** 一条修改提交时发现这条待办已在别处改过，就保留在原处并标出冲突，由用户选择「用我的版本」（以最新版本为基础重新提交）或「保留电脑上的」（丢弃我的修改）。
- **标签**：副本显示并从主力电脑的标签目录里选，不使用本机目录；副本上不能新建标签。
- **提醒只在主力电脑上触发**（以及没开同步的电脑），副本不弹提醒；换主力电脑后新主力电脑开始提醒。
- **换主力电脑**：在副本上点「设为主力电脑」。旧主力电脑在线时先取它的最新数据并交接；不在线时以本机镜像为准接管，旧主力电脑上线后自动降为副本，并把它在降级前独有的修改作为待发修改提交。
- **被拒的新建不丢**：主力电脑拒绝一条这里新建的待办时，它作为带冲突标记的草稿行留在列表里，选「用我的版本」会换新的请求号重新提交，选「保留电脑上的」则丢弃。
- 页头状态：主力电脑名称（副本）、已同步、待同步 N、主力电脑离线、主力电脑未开启远程控制；界面只放这些标签与数值，不放说明文字。
- Agent：`list_personal_todos` 带 `sync` 概况；副本上 `update_personal_todo` 最多等 3 秒（只等引擎自己的发送，不额外请求）：主力电脑已接收返回 `sync: 'synced'`（带主力电脑的 id 与 revision），否则 `'pending'`（已记在本机，不是失败）。开关、设为主力电脑与冲突处理有 `get_personal_todo_sync` / `set_personal_todo_sync` / `resolve_personal_todo_conflict`，见 [Agent 与用户同权](agent-user-parity.md)。
- 页头状态随同账号电脑上下线、开关远程控制即时更新（设备在线信号），每 2 分钟的本地重读只作兜底。
