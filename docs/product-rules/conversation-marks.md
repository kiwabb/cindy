# 对话标记（2026-11-19，fork 专有）

> 依据：主人确认的原型（2026-11-19，「都可以，按这个开工」）；同步沿用
> [共享数据集](../shared-datasets-plan.md)，是个人待办之后的第二个数据集。

伙伴一次回复常讲好几点，主人先挑一点聊清楚再聊下一点；聊完后原来那条消息很难翻到。
标记让主人在对话里把要回头聊的几段话记下来，在右侧栏逐条处理。

## 行为

- **标记**：在伙伴对话里选中一段文字（伙伴的或主人自己的都可以），选中浮层在「添加到对话」后面
  出现「标记」（荧光笔图标）。只在选区整体落在一条消息里时出现；文件浏览器等复用这个浮层的
  地方不出现。摘录最多存 600 字，超出截断并加省略号。
- **原文底色**：未聊的标记用搜索命中色调淡并加同色系下划线，已聊的改成中性灰底与灰下划线
  （设计登记见 [DESIGN.md §2](../design-rules/DESIGN.md)「Search matches」）。用 CSS 自定义高亮绘制，
  不改消息 DOM；消息重新渲染后按保存的位置重画，位置对不上时按摘录原文查找，仍找不到就不画。
- **入口**：普通伙伴对话在顶栏右侧，荧光笔图标加未聊数量，点开右侧栏「标记」页签；导师对话
  （本机、绑定了进行中的学习目标）不放顶栏入口，「标记」页签自动加在「今天」旁边，页签上显示未聊数。
- **列表**：每条显示摘录、来自谁（主人自己的消息显示「我」，伙伴的显示标记时的伙伴名）、消息时间
  （今天显示时分，昨天显示「昨天 16:05」，更早显示月日）。未聊在上、已聊在下，中间分隔线；
  组内按消息在对话里的先后排（同一条消息里按位置），不按标记时间。
- **跳转**：点一条标记，对话滚回原消息，沿用现有的消息定位（`requestChatTaskFocus`：不在已加载
  范围时先 `loadAroundMessageClientId` 再定位，失败提示「跳转失败」）与 1.2 秒整条消息高亮。
- **状态**：未聊 / 已聊，勾选用个人待办同款完成圈。已聊变灰沉底，不自动删除，不显示「就聊这点」，
  只留删除。删除不弹确认，提示条里给「撤销」（`toast` 的 action，6 秒），撤销即恢复原状态。
- **就聊这点**：把摘录作为引用放进输入框，走「添加到对话」的同一个 `appendQuoteToDraft`，不自动发送。
- **空状态**：一个图标加「还没有标记」。
- **窄窗口**（窗口宽 ≤ 960px；应用最小宽度是 800px，这时侧栏只剩一百多像素宽）：「标记」页签在前台时右侧栏占满内容区（沿用侧栏最大化），
  左上角「返回对话」关闭侧栏；在窄窗口里点标记或「就聊这点」也会先回到对话。

## 数据与归属

- 标记是主人自己的笔记：不进模型、不进对话记录，伙伴没有读写标记的工具。
- 一条标记属于一场对话，用「对话所在电脑的 id + 任务 id + 消息 `clientId`」指认。远程打开另一台电脑
  的对话时，三者与那台电脑上看到的相同（远程查看不改写 id），所以同一条标记在两台电脑上都能找回原文。
  本机对话的标记在写入时补上本机 id；本机还不知道自己的 id 时先空着，加入同步时补上。
- 远程对话的标记存在**当前这台电脑**上（按那台电脑的 id 归类），不写到对话所在的电脑。
- 存储与同步见 [本地存储](../dev-rules/credentials-and-local-storage.md)「对话标记」行与
  [协议记录](../dev-rules/protocol-compatibility/shared-datasets.md)「对话标记数据集」。

## 多台电脑同步

- 标记没有自己的开关：跟随「在多台电脑间同步待办」。待办同步开着，标记也同步；关掉，标记也停止
  同步（各电脑留着自己当时的那份）。这台电脑成为待办的主力电脑时，也接管标记的主力电脑。
- 列表顶部右侧一行三级文字显示同步状态：已同步、同步中、离线 · N 条待同步；离线时本机改过、
  主力电脑还没收到的条目在时间后面加一个小图标。没有横幅。
- 两台电脑同时改了同一条标记时以主力电脑为准，不出冲突列表。

## 已知限制

- 伙伴换了主力电脑、或伙伴的主任务被替换后，旧对话里的标记仍指向原来那台电脑上的那场对话，
  在新对话里不显示。
- 「待同步」小图标只在本次运行里记得；重启后同步状态那一行的计数仍准确，但单条的图标要等下次修改。
- 侧栏放在独立窗口时，顶栏入口只在主窗口的侧栏里打开页签。
